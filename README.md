# Atlas of Imagined Futures (prototype)

An interactive prototype of the Atlas of Imagined Futures, built for the John Templeton Foundation proposal *The Grammar of Tomorrow: Religious, Philosophical, and Narrative Traditions as Architects of Future-Mindedness* (Arizona State University, University of Utah, University of Massachusetts Amherst).

Every respondent, country profile, and glyph on the site is simulated. The page says so on every screen. The prototype shows what the Atlas will do once the Aim 1 multinational survey supplies real data.

The site is a single static page (`index.html`) plus one data file (`world.json`), served with GitHub Pages. It loads D3 v7 from cdnjs and nothing else.
